# Community standards

CraftLayer is a project for people with different backgrounds, experience,
identities, and opinions. We want participation to be constructive,
respectful, and focused on improving the work.

## Expected behavior

- Be respectful and assume good intent while discussing disagreements.
- Give specific, actionable feedback about the work rather than attacking
  contributors.
- Welcome questions and explain project context without condescension.
- Respect privacy; do not post credentials, private user data, or sensitive
  security reports in public discussions.
- Be honest about evidence, uncertainty, limitations, and attribution.

## Unacceptable behavior

- Harassment, threats, discrimination, or personal attacks.
- Publishing another person's private information without permission.
- Deliberate disruption, intimidation, or repeated bad-faith conduct.
- Plagiarism or knowingly false claims about authorship, testing, sources,
  licensing, or product capabilities.

## Maintainer response

Maintainers may edit or remove harmful content, close discussions, or limit
participation when needed to keep the project safe and productive. Actions
should be proportionate to the behavior and explained where practical.

If a public discussion is not an appropriate place to raise a concern, use
GitHub's private contact options for the repository maintainers. Do not
include sensitive personal data in a public issue.

## Scope

These standards apply in CraftLayer repositories, issues, pull requests,
discussions, and project-related community spaces.
