# Asset registry policy

`asset-registry.json` is intentionally empty: no third-party assets are
currently bundled. Add an asset only after
verifying its source, license, attribution requirements, permitted uses, and
technical format. Record these details in the asset registry before
including the asset in a release.

When rights are unclear, link to the original source instead of copying the
asset. Do not invent product screenshots, customer marks, or proof.
